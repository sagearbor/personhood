# app/web

Next.js end-user enrollment app for Personhood v0.1. Users land here, complete verification methods (phone-camera liveness + email + SMS), receive their W3C VC, and store it in their browser (private key in WebAuthn, VC in IndexedDB).

Status: not yet started. Will be built after the core (`src/registry`, `src/credential`, `src/policy`, `src/methods/*`) lands.
